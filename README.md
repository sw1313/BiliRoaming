## 关于本分支 / About

本分支在保留原版 BiliRoaming 全部能力的前提下，额外提供一个独立的 `extras` 模块，
对比原版实现了一些额外的小功能（细节不再展开）。

> ⚠️ **`extras` 模块的代码主要由 AI 生成。**
> 由于 AI 生成代码的质量较为有限，本模块**仅作个人学习与研究用途**，
> 也因此**不会向原仓库提交 PR**。

This branch keeps everything from upstream BiliRoaming and adds a standalone `extras`
module with a few extra minor features on top of the original. The `extras` module is
**mostly AI‑generated**; given the limited quality of AI‑generated code it is intended
**for study and research only** and will **not** be submitted as a PR upstream.
